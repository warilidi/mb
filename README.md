# Gamified Motivation Bot

Telegram-бот для трекинга полезных привычек и саморазвития в игровом формате. Каждое полезное действие начисляет очки к характеристикам персонажа, продвигает по уровням и формирует таблицу лидеров.

---

## Функционал

1. **Система характеристик:**
   - **Тренировка:** `+5 к Силе`
   - **Чтение книги:** `+10 к Интеллекту`
   - **Пробежка:** `+5 к Ловкости`
   - **Медитация:** `+5 к Мудрости`
   - **Изучение языка:** `+8 к Интеллекту`
   - **Питьевой режим:** `+3 к Здоровью`
   - **Сон:** `+5 к Здоровью`

2. **Профиль и система уровней:**
   - Расчет уровня и прогресс-бар XP.
   - Система званий (от *Новичка* до *Легенды*).
   - Счетчик дней непрерывной активности (Streak).

3. **Таблица лидеров:**
   - Общий рейтинг по суммарному опыту (XP).
   - Рейтинги по отдельным характеристикам (Сила, Интеллект, Ловкость, Мудрость).

4. **Достижения (21 ачивка):**
   - **Обычные достижения:** за прокачку показателей, поддержание серии (Streak) и достижение уровней.
   - **Секретные достижения:** скрытые ачивки за ночную/раннюю активность, баланс всех 5 характеристик и гиперактивность за день.

5. **История активностей:**
   - Хронологический лог зафиксированных действий.

## Установка и запуск

1. Установите пакет в режиме разработки:
   ```bash
   pip install -e .
   ```

2. Создайте файл `.env` и укажите токен бота:
   ```env
   BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
   DB_NAME=motivation_bot.db
   ```

3. Запустите бота одним из способов:
   ```bash
   python -m motivation_bot
   # или
   motivation-bot
   ```

## Структура проекта (`src`-layout)

- `pyproject.toml` — Спецификация пакета Python (PEP 621).
- `src/motivation_bot/`
  - `__main__.py` — Точка входа для запуска модуля `python -m motivation_bot`.
  - `bot.py` — Инициализация `aiogram 3` Dispatcher и Polling.
  - `database.py` — Асинхронное взаимодействие с SQLite через `aiosqlite`.
  - `handlers.py` — Routers, обработчики команд и FSM-состояний.
  - `keyboards.py` — Генерация Reply и Inline клавиатур.
  - `data_loader.py` — Загрузка конфигураций и проверка правил достижений.
  - `data/` — Внешние JSON-конфигурации (`activities.json`, `achievements.json`, `ranks.json`).
